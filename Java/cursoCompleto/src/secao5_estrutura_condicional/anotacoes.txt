OPERADORES COMPARATIVOS (C, C++, JAVA, C#):
    > "maior que";
    < "menor que";
    >= "maior, ou igual, que";
    <= "menor, ou igual, que";
    == "igual";
    != "diferente".

EXPRESSÕES LÓGICAS (C, C++, JAVA, C#):
    && -> "e" (cada opção deve ser VERDADEIRA);
        Ex.: Você pode obter uma habilitação de motorista se:
            * for aprovado no exame psicotécnico
                E
            * for aprovado no examae de legislação,
                E
            * for aprovado no exame de direção.
        Ex.: Suponha x igual a 5
            X <= 20 && X == 10 -> RESULTADO: F
            X > 0 && X != 3 -> RESULTADO: V
            X <= 20 && X == 10 && X != 3 -> RESULTADO: F
    || -> "ou" (pelo menos uma condição deve ser verdadeira);
        Ex.: Você pode estacionar na vaa especial se:
            * For idoso(a),
                OU
            * For uma pessoa com deficiência,
                OU
            * For uma gestante
        Ex.: Suponha x igual a 5
            X == 10 || X <= 20 -> RESULTADO: V
            X > 0 || X != 3 -> RESULTADO: V
            X <= 0 || X !+ 3 || X != 5 -> RESULTADO: V
    ! -> "não" (Condição negativa: Se a condição for falsa, ela se torna verdadeira. Entretanto, se ela for verdadeira, ela se torna falsa)
       Ex.: Você tem direito a receber uma bolsa de estudos se você:
               NÃO
           * possuir rendar maior que R$ 3000,00
       Ex.: Suponha x igual a 5
       !(X <= 20 && X == 10) -> RESULTADO: V

       * OPERADORES DE ATRIBUIÇÃO ACUMULATIVA:
        //Quando se usam um conjunto de operadores de forma estratégica para acumular um valor dentro de uma variável, reutilizando-a para acrescemtar este valor
       --> a += b (a = a + b);
       --> a -= b (a = a - b);
       --> a *= b (a = a * b);
       --> a /= b (a = a / b);
       --> a %= b (a = a % b);

       * SWITCH CASE --> Estrutura de controle
       --> Compara os valores dentro de um código, permitindo a execução de múltiplas condições;
       --> Alternativa do if-else-if

       Ex.: X = 0
            switch(x) {
            case 1:
                x += 1;
                System.out.println("SOMANDO");
                break;
            case 2:
                x *= 2;
                System.out.println("MULTIPLICANDO")
                break;
            default:
                X = 3;
                System.out.println("X É 3")
                break;
            }

       * EXPRESSÃO CONDICIONAL TERNÁRIA:
        --> Estrutura opcional ao if-else quando se deseja decidir um valor com base em uma condição

        Sintaxe: (condição) ? valor_se_verdadeiro : valor_se_falso

        Ex.: double preco = 34.5;
             double desconto = (preco < 20.0) ? preco * 0.1 : preco * 0.05;

             <RESPOSTA> -> (preco * 0.05)
