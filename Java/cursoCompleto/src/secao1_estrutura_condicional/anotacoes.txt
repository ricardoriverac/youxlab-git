OPERADORES COMPARATIVOS (C, C++, JAVA, C#):
    > "maior que";
    < "menor que";
    >= "maior, ou igual, que";
    <= "menor, ou igual, que";
    == "igual";
    != "diferente".

EXPRESSÕES LÓGICAS (C, C++, JAVA, C#):
    && -> "e" (cada opção deve ser VERDADEIRA);
        Ex.: Você pode obter uma habilitação de motorista se:
            * for aprovado no exame psicotécnico
                E
            * for aprovado no examae de legislação,
                E
            * for aprovado no exame de direção.
        Ex.: Suponha x igual a 5
            X <= 20 && X == 10 -> RESULTADO: F
            X > 0 && X != 3 -> RESULTADO: V
            X <= 20 && X == 10 && X != 3 -> RESULTADO: F
    || -> "ou" (pelo menos uma condição deve ser verdadeira);
        Ex.: Você pode estacionar na vaa especial se:
            * For idoso(a),
                OU
            * For uma pessoa com deficiência,
                OU
            * For uma gestante
        Ex.: Suponha x igual a 5
            X == 10 || X <= 20 -> RESULTADO: V
            X > 0 || X != 3 -> RESULTADO: V
            X <= 0 || X !+ 3 || X != 5 -> RESULTADO: V
    ! -> "não" (Condição negativa: Se a condição for falsa, ela se torna verdadeira. Entretanto, se ela for verdadeira, ela se torna falsa)
       Ex.: Você tem direito a receber uma bolsa de estudos se você:
               NÃO
           * possuir rendar maior que R$ 3000,00
       Ex.: Suponha x igual a 5
       !(X <= 20 && X == 10) -> RESULTADO: V
