EXERCÍCIO 1

Pedi para que o usuário digite um nome idade e nota média em seguida calculando quantos anos faltará para que ele chegue a 100 anos, e também faça um cálculo para saber se a nota digitada está na média ou não de uma turma e no final exibindo todas as informações em ordem organizadamente

EXERCÍCIO 2

o programa pede para ler cinco números inteiros armazenados em uma lista e em seguida exibi-los como maior, menor e média todos números digitados no final pede-se para que informe um número da lista e se ele estiver na lista em qual posição ele está.

EXERCICIO 3
Nesse código é necessário fazer o cadastro de um aluno perguntando nome e as suas notas em seguida fazendo o cálculo da média de notas do aluno, depois perguntando ao usuário qual o aluno ele quer ver as notas

EXERCÍCIO 4

Nesse programa pede para que cadastre três alunos e exiba um relatório completo com o nome e notas como se fosse um dicionário exemplo Maria : 8.5 : Aprovada 

EXERCÍCIO 5

O quinto e último exercício pede para que crie uma lista de tarefas assim que forem adicionadas as tarefas organizadamente, assim que uma fosse feita a pessoa pode marcar um x de feito o programa só termina quando o usuário escolher sair.
